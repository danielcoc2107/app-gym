## Revisión manual

Iniciar con `npm run dev` y abrir [App Gym local](http://127.0.0.1:3000).
Para revisar exactamente la compilación, usar `npm run build` y `npm run start`.
El servidor de E2E usa otro puerto, el 3100, y se cierra al terminar la suite.

1. Abrir inicio en escritorio y móvil: textos legibles y sin desplazamiento horizontal.
2. Pulsar «Conoce cómo funciona» y «Volver al inicio».
3. Usar Tab y Enter para comprobar «Saltar al contenido» y los enlaces.
4. Visitar una ruta inexistente y volver desde la página 404.
5. Confirmar que se anuncian funciones futuras y no se simulan datos guardados.

Se inspeccionaron inicio y «Cómo funciona» en escritorio (1365 × 900) y móvil
(390 × 844), con navegación de ida y vuelta y sin avisos/errores de consola observados.
El tamaño del navegador se restauró al finalizar la revisión.
